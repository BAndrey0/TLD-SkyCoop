# TLD-SkyCoop — кооператив для The Long Dark 2.55

Кооперативное **Выживание** для The Long Dark (Steam, Survival 2.55, build 22915504) на основе
[Sky Co-op](https://github.com/Filigrani/SkyCoop) от Filigrani и адаптации
[SkyCoop-Upadated](https://github.com/DoperDodge/SkyCoop-Upadated) под Unity 6 / MelonLoader 0.7.3.

Сюжетный режим не поддерживается. Мод экспериментальный: перед долгой игрой делайте копию `player\saves`.

## Установка для игроков

1. У каждого игрока своя Steam-копия The Long Dark **версии 2.55** (build 22915504) и запущенный Steam.
2. Скачать архив `TLD-SkyCoop-<версия>.zip` со страницы [Releases](../../releases) и распаковать в папку
   с латинским путём, например `D:\TLD-Coop` (получится `D:\TLD-Coop\friend-kit`).
3. Запустить `friend-kit\Install.cmd` и указать папку игры Steam, если её не нашло само.
   Установщик:
   - делает **отдельную копию игры** рядом (`D:\TLD-Coop\player`, ~21 ГБ) — оригинальная игра и её сохранения не трогаются;
   - скачивает с официальных страниц MelonLoader 0.7.3, .NET 6 runtime и ресурсы Sky Co-op v13.2 и проверяет их хеши;
   - кладёт моды из `friend-kit\files`.
4. Играть через `player\Play-Coop.cmd`.

**Обновление:** распаковать новый архив поверх, заменив `friend-kit`, и запустить `friend-kit\Update.cmd`.
Папку `player` (там сохранения) не удалять. Версии у всех игроков должны совпадать — сервер не пускает другую.

Как играть, что изменено и известные ограничения — в [kit/README-RU.md](kit/README-RU.md) (этот же файл лежит в архиве).

## Что исправлено относительно SkyCoop 0.14.1

- **Общий разбросанный лут.** Мод делает лут одинаковым у всех через сид, в который подмешивался
  `string.GetHashCode()` — в .NET 6 он случайный в каждом процессе, поэтому у каждого игрока лежали разные вещи.
  Заменён на детерминированный хеш (`Shared.StableHash`); то же для ключей брошенных/переданных предметов.
- Выбор сложности запускал испытание: режим брался по номеру строки меню из списка всех режимов игры.
- «Назад» в лобби оставлял меню в неработающем состоянии; «Назад» на карте регионов ничего не делал.
- Луч электрического фонарика другого игрока не отображался (код синхронизации не был подключён).
- В обысканный контейнер нельзя было положить вещи — повторное открытие теперь показывает окно переноса.
- Старт сервера падал из-за животного без `ObjectGuid` — друзья не могли подключиться.
- Регион в интерьерах определялся по куску имени сцены (`HouseBasementPV` → Тихая долина).
- Выбор персонажа при входе открывался до 5 раз из-за повторных пакетов.
- Ветки, камни и перья не синхронизировались даже с выключенными дубликатами.
- Порча вещей была выключена всегда — теперь настройка `EnableItemDecay` (раздел `[SkyCoop]` в `UserData\MelonPreferences.cfg`).
- Подключение по IP могло брать IPv6 link-local адрес; спам «No ViewModelRadio mesh» в логе; сторож записи на диск при выходе.

## Сборка из исходника

Исходник получен декомпиляцией SkyCoop 0.14.1 (ILSpy) и правится как обычный C#-проект.

Нужно:
- .NET SDK 6+ (подойдёт 8.0);
- установленная через `Install.cmd` копия игры, хотя бы раз запущенная: MelonLoader генерирует в
  `player\game\MelonLoader\Il2CppAssemblies` сборки игры, на которые ссылается проект. В репозитории их нет.

По умолчанию проекты ищут игру в `..\..\player\game` относительно себя, то есть репозиторий удобно клонировать
рядом с `player`: `D:\TLD-Coop\TLD-SkyCoop`. Иначе укажите путь явно:

```
dotnet build SkyCoop\SkyCoop.csproj -c Release -p:GameDir=D:\TLD-Coop\player\game
```

Собрать архив для игроков (DLL, manifest с хешами, скрипты, лицензии):

```
powershell -ExecutionPolicy Bypass -File tools\package.ps1 -GameDir D:\TLD-Coop\player\game
```

Результат — `out\TLD-SkyCoop-<версия>.zip`. При изменении сетевого протокола поднимайте версию (строки `0.14.x`
в `SkyCoop`), иначе игроки с разными сборками смогут подключиться друг к другу.

## Структура

| Папка | Что внутри |
|---|---|
| `SkyCoop/` | основной мод (MelonLoader, Harmony) |
| `CoopProfile/` | маленький мод: переносит сохранения кооп-копии в `player\saves` |
| `kit/` | установщик, лаунчер, обновление и README для игроков |
| `tools/package.ps1` | сборка архива для игроков |
| `licenses/` | лицензии Sky Co-op и Steamworks.NET |
